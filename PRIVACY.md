# Confidentialité / Privacy

*English below.*

## Français

*Dernière mise à jour : 26 septembre 2026*

AppToggle ne collecte, ne stocke et ne transmet **aucune donnée personnelle**.

- **Aucune connexion Internet** : AppToggle n'envoie et ne reçoit rien. Le seul lien, « Code source sur GitHub », ouvre ton navigateur quand tu cliques dessus.
- **Réglages locaux** : tes raccourcis (nom de l'appli, touche, chemin du programme) sont enregistrés uniquement sur ton PC, dans le fichier `config.ini`. Dans la version du Microsoft Store, ce fichier se trouve dans ton dossier utilisateur Windows (`AppData`).
- **Clavier** : pour reconnaître certaines touches (dont la touche Copilot), AppToggle utilise un crochet clavier de Windows. Il ne sert qu'à reconnaître les raccourcis que tu as choisis : aucune frappe n'est enregistrée, stockée ou envoyée.
- **Fenêtres ouvertes** : quand tu cliques sur « Choisir une appli ouverte », AppToggle lit la liste des fenêtres ouvertes pour te la proposer. Cette liste reste sur ton PC et n'est pas conservée.
- **Pas de publicité, pas de statistiques, pas de compte.**

Tu peux supprimer toutes les données d'AppToggle en le désinstallant, ou en supprimant son fichier `config.ini`.

Question ou problème : [ouvrir une issue sur GitHub](https://github.com/RobinsanKiritheepan/AppToggle/issues).

## English

*Last updated: September 26, 2026*

AppToggle does not collect, store or transmit **any personal data**.

- **No internet connection**: AppToggle never sends or receives anything. The only link, "Source code on GitHub", opens your browser when you click it.
- **Local settings**: your shortcuts (app name, key, program path) are saved only on your PC, in the `config.ini` file. In the Microsoft Store version, this file is stored in your Windows user folder (`AppData`).
- **Keyboard**: to recognize some keys (including the Copilot key), AppToggle uses a Windows keyboard hook. It is only used to recognize the shortcuts you chose: no keystroke is recorded, stored or sent.
- **Open windows**: when you click "Pick an open app", AppToggle reads the list of open windows to show it to you. This list stays on your PC and isn't kept.
- **No ads, no analytics, no account.**

You can remove all of AppToggle's data by uninstalling it, or by deleting its `config.ini` file.

Questions or issues: [open an issue on GitHub](https://github.com/RobinsanKiritheepan/AppToggle/issues).
